# 실습과제1

### 1. 표준 입출력 스트림을 접근하는 방법을 설명하라.
- 표준 입출력 스트림은 stdin, stdout, stderr를 통해 접근한다.
- stdin은 표준 입력, stdout은 표준 출력, stderr는 표준 오류 출력에 사용한다.

### 2. 공백을 포함한 문자열을 입력받을 때 사용 가능한 함수는?
- fgets() 함수를 사용한다.
- fgets()는 공백을 포함한 문자열을 입력받을 수 있으며, 버퍼 크기를 지정할 수 있다.

### 3. gets 함수 사용 시 가장 큰 문제점은 무엇인가?
- 입력받을 문자열의 크기를 제한하지 않아 버퍼 오버플로가 발생할 수 있다.
- 이러한 문제로 인해 gets()는 C11 표준에서 제거되었다.

### 4. fgets 함수 사용 시 문제점은 무엇인가?
- 입력 문자열에 개행 문자가 포함될 수 있다.
- 버퍼 크기에 따라 문자열이 잘릴 수 있으며, 남은 입력이 입력 스트림에 남을 수 있다.

### 5. 널 문자('\0')와 널 포인터(NULL)의 용도를 설명하시오.
- 널 문자('\0')는 문자열의 끝을 나타내는 문자이다.
- 널 포인터(NULL)는 유효한 객체나 함수 등을 가리키지 않는 포인터 값이다.
# 실습과제2

```c
void printString(const char* str)
```
- 문자열을 문자 단위로 출력하기 위한 함수를 선언한다.

```c
while (*str != '\0')
```
- 문자열의 끝인 널 문자가 나올 때까지 반복한다.

```c
putchar(*str);
```
- 현재 문자를 화면에 출력한다.

```c
str++;
```
- 포인터를 다음 문자 위치로 이동한다.

```c
char ch;
```
- 입력받은 문자를 저장할 변수를 선언한다.

```c
while (1)
```
- 문자를 반복해서 입력받기 위해 무한 반복문을 사용한다.

```c
ch = getchar();
```
- 키보드에서 문자 하나를 입력받는다.

```c
if (ch == 'q' || ch == 'Q')
```
- 입력한 문자가 소문자 q 또는 대문자 Q인지 확인한다.

```c
break;
```
- 반복문을 종료한다.

```c
if (ch == '\n')
```
- 입력받은 문자가 엔터 문자인지 확인한다.

```c
continue;
```
- 엔터 문자는 출력하지 않고 다음 반복으로 넘어간다.

```c
putchar(ch);
```
- 입력받은 문자를 화면에 출력한다.

```c
putchar('\n');
```
- 줄을 바꾼다.

```c
while ((ch = getchar()) != '\n' && ch != EOF)
```
- 입력 줄에 남아 있는 문자를 엔터 또는 입력 종료까지 읽는다.

```c
return 0;
```

# 실습과제4

```c
char str[20];
```
- 문자열을 저장할 크기 20의 문자 배열을 선언한다.

```c
printf("문자열입력:");
```
- 사용자에게 문자열 입력을 요청하는 문구를 출력한다.

```c
fgets(str, sizeof(str), stdin);
```
- 표준 입력으로 문자열을 입력받으며, 엔터 문자가 배열에 저장될 수 있다.

```c
for (int i = 0; str[i] != '\0'; i++)
```
- 널 문자('\0')를 만날 때까지 배열의 문자를 하나씩 확인한다.

```c
if (str[i] == '\n')
```

```c
str[i] = '\0';
```
- 개행 문자를 널 문자로 바꾸어 문자열 끝으로 만든다.

```c
break;
```
- 개행 문자를 찾았으므로 반복문을 종료한다.

```c
printf("%s", str);
```
- 개행 문자가 제거된 문자열을 출력한다.

```c
return 0;

# 실습과제5

```c
char str[100];
```
- 문자열을 입력받아 저장할 문자 배열을 선언한다.

```c
int count = 0;
```
- 문자열에 포함된 단어의 개수를 저장할 변수를 0으로 초기화한다.

```c
int inWord = 0;
```
- 현재 단어 안에 있는지 확인하기 위한 변수를 선언한다.

```c
fgets(str, sizeof(str), stdin);
```
- 공백을 포함한 문자열을 입력받는다.

```c
for (int i = 0; str[i] != '\0'; i++)
```
- 문자열의 끝에 도달할 때까지 한 문자씩 확인한다.

```c
if (str[i] == ' ' || str[i] == '\n' || str[i] == '\t')
```
- 현재 문자가 공백, 개행 문자 또는 탭 문자인지 확인한다.

```c
inWord = 0;
```
- 단어가 끝났으므로 단어 밖에 있는 상태로 변경한다.

```c
else if (inWord == 0)
```
- 단어 밖에 있다가 새로운 단어를 시작하는지 확인한다.

```c
count++;
```
- 새로운 단어가 시작되었으므로 단어 개수를 1 증가시킨다.

```c
inWord = 1;
```
- 현재 단어 안에 있는 상태로 변경한다.

```c
printf("단어수 : %d\n", count);
```
- 계산한 단어 개수를 화면에 출력한다.

```c
return 0;
```
- 프로그램을 정상적으로 종료한다.
```
