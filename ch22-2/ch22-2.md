# 실습과제1
- `struct student list[3];`
  - student 구조체를 이용하여 학생 3명의 정보를 저장할 배열을 선언한다.

- `for (int i = 0; i < 3; i++)`
  - 반복문을 이용하여 학생 3명의 이름과 성적을 입력받는다.

- `scanf("%s", list[i].name);`
  - 구조체 배열을 이용하여 학생의 이름을 입력받는다.

- `scanf("%d", &list[i].grade);`
  - 구조체 배열을 이용하여 학생의 성적을 입력받는다.

- `int max = list[0].grade;`
  - 첫 번째 학생의 성적을 최대 성적의 기준으로 설정한다.

- `char maxname[10];`
  - 최대 성적을 받은 학생의 이름을 저장할 문자 배열을 선언한다.

- `strcpy(maxname, list[0].name);`
  - 첫 번째 학생의 이름을 maxname 배열에 복사한다.

- `for (int i = 1; i < 3; i++)`
  - 두 번째 학생부터 세 번째 학생까지 성적을 비교한다.

- `if (max < list[i].grade)`
  - 현재 학생의 성적이 기존 최대 성적보다 높은지 비교한다.

- `max = list[i].grade;`
  - 현재 학생의 성적이 더 높으면 최대 성적을 갱신한다.

- `strcpy(maxname, list[i].name);`
  - 최대 성적을 받은 학생의 이름을 maxname 배열에 복사한다.

- `printf("%s, %d", maxname, max);`
  - 최대 성적을 받은 학생의 이름과 성적을 출력한다.

# 실습과제3
- `struct student* p;`
  - student 구조체를 가리키는 포인터 변수 p를 선언한다.

- `p = list;`
  - 구조체 배열 list의 첫 번째 요소를 가리키도록 포인터를 초기화한다.

- `scanf("%9s", p->name);`
  - 포인터를 이용하여 학생의 이름을 입력받는다.

- `scanf("%d", &p->grade);`
  - 포인터를 이용하여 학생의 성적을 입력받는다.

- `p++;`
  - 포인터를 다음 구조체 배열 요소로 이동시킨다.

- `max = list;`
  - 가장 높은 성적을 가진 학생을 찾기 위해 첫 번째 학생을 최대 성적의 기준으로 설정한다.

- `for (p = list + 1; p < list + 3; p++)`
  - 두 번째 학생부터 세 번째 학생까지 포인터를 이동하며 성적을 비교한다.

- `if (p->grade > max->grade)`
  - 현재 학생의 성적이 최대 성적보다 높으면 최대 성적을 가진 학생의 위치를 변경한다.

- `max = p;`
  - 현재 학생을 최대 성적을 가진 학생으로 지정한다.

- `printf("이름은 %s, 점수는 %d점\n", max->name, max->grade);`
  - 가장 높은 성적을 받은 학생의 이름과 점수를 출력한다.

# 실습과제4
- `struct point`
  - 2차원 평면의 점을 표현하기 위해 x좌표와 y좌표를 저장하는 구조체를 정의한다.

- `struct triangle`
  - point 구조체를 이용하여 삼각형의 세 점을 저장하는 구조체를 정의한다.

- `struct triangle t;`
  - 삼각형의 세 점을 저장할 구조체 변수 t를 선언한다.

- `scanf("%d %d", &t.p1.x, &t.p1.y);`
  - 첫 번째 점의 x좌표와 y좌표를 입력받는다.

- `a`, `b`, `c`
  - 삼각형을 이루는 세 변의 길이의 제곱을 저장한다.

- `a = (t.p1.x - t.p2.x) * (t.p1.x - t.p2.x) + (t.p1.y - t.p2.y) * (t.p1.y - t.p2.y);`
  - 첫 번째 점과 두 번째 점 사이의 거리의 제곱을 계산한다.

- `b`와 `c`의 계산
  - 나머지 두 변의 거리의 제곱을 각각 계산한다.

- `if (a + b == c || a + c == b || b + c == a)`
  - 피타고라스 정리를 이용하여 세 변 중 두 변의 제곱의 합이 나머지 한 변의 제곱과 같은지 확인한다.

- `printf()`
  - 조건에 따라 직각삼각형인지 아닌지를 출력한다.
