# 실습과제1

```c
int arr1[2][2] = { {2, 4}, {5, -5} };
int arr2[2][2] = { {-2, 3}, {0, -5} };
```
- 2차원 배열 arr1과 arr2에 각각 2행 2열의 정수를 저장한다.

```c
int arr3[2][2];
```
- 두 배열의 덧셈 결과를 저장할 2차원 배열 arr3을 선언한다.

```c
arr3[i][j] = arr1[i][j] + arr2[i][j];
```
- 같은 행과 열에 있는 배열의 원소끼리 더하여 arr3에 저장한다.

```c
printf("%d  ", arr3[i][j]);
```
- 계산된 결과를 행과 열의 순서대로 출력한다.

# 실습과제2

```c
int arr[3][3];
double avg[3];
int best = 0;
```
- 3명의 학생의 국어, 영어, 수학 점수를 저장할 2차원 배열을 선언한다.
- 각 학생의 평균 점수를 저장하기 위해 avg 배열을 선언한다.
- 현재 가장 높은 평균을 가진 학생의 번호를 best에 저장한다.

```c
scanf("%d", &arr[j][i]);
```
- 각 학생의 국어, 영어, 수학 점수를 입력받아 배열에 저장한다.

```c
sum += arr[j][i];
```
- 한 학생의 세 과목 점수를 더하여 총점을 계산한다.

```c
avg[j] = sum / 3.0;
```
- 총점을 3으로 나누어 학생의 평균 점수를 계산한다.
- 3.0으로 나누어 실수 형태의 평균을 구한다.

```c
if (avg[j] > avg[best])
    best = j;
```
- 현재 학생의 평균이 지금까지 가장 높은 평균보다 크면 best를 현재 학생의 번호로 변경한다.

```c
printf("최우수 학생은 %d번째 학생이고 평균점수는 %f점이다.\n",
    best + 1, avg[best]);
```
- 가장 높은 평균을 가진 학생의 번호와 평균 점수를 출력한다.

# 실습과제3

```c
int arr[3][3] = {
    { -5, 2, 35 },
    { -20, 5, 100 },
    { -75, 5, -25 }
};
```
- 3행 3열의 2차원 배열에 정수를 저장한다.

```c
int x = 0;
int y = 0;
int max = arr[0][0];
```
- 최대값의 행과 열을 저장할 변수 x와 y를 선언한다.
- 배열의 첫 번째 값을 최대값으로 설정한다.

```c
if (max < arr[i][j])
```
- 현재 저장된 최대값보다 배열의 현재 원소가 큰지 비교한다.

```c
x = i;
y = j;
max = arr[i][j];
```
- 더 큰 값을 찾으면 해당 값과 행, 열의 위치를 저장한다.

```c
printf("최대값은: %d, 위치는 %d행 %d열", max, x + 1, y + 1);
```
- 최대값과 배열에서의 위치를 출력한다.
- 배열의 인덱스는 0부터 시작하므로 실제 행과 열을 표시하기 위해 1을 더한다.

# 실습과제4

```c
char str[4][10];
```
- 최대 10개의 문자를 저장할 수 있는 문자열 4개를 2차원 배열로 선언한다.

```c
scanf("%s", str[i]);
```
- 사용자에게 문자열을 입력받아 배열에 저장한다.

```c
while (str[i][j] != '\0')
```
- 문자열의 끝을 나타내는 널 문자 '\0'이 나올 때까지 반복한다.

```c
cnt++;
j++;
```
- 문자의 개수를 하나 증가시키고 다음 문자로 이동한다.

```c
printf("%d번째 문자열길이: %d\n", i + 1, cnt);
```
- 각 문자열의 길이를 출력한다.
- 문자열 라이브러리 함수를 사용하지 않고 직접 문자를 하나씩 확인하여 길이를 계산한다.

# 실습과제5

```c
char str[4][10];
int last = 0;
```
- 최대 10개의 문자를 저장할 수 있는 문자열 4개를 배열에 저장한다.
- 현재 사전 순서에서 가장 뒤에 있는 문자열의 위치를 last에 저장한다.

```c
scanf("%s", str[i]);
```
- 4개의 문자열을 입력받아 배열에 저장한다.

```c
if (str[last][0] < str[i][0])
```
- 현재 가장 뒤에 있는 문자열의 첫 번째 문자와 현재 문자열의 첫 번째 문자를 비교한다.

```c
last = i;
```
- 현재 문자열의 첫 번째 문자가 더 뒤에 있으면 last를 현재 문자열의 위치로 변경한다.
