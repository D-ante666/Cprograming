# 실습과제1
- 구조체는 서로 다른 자료형의 데이터를 하나로 묶어서 관리하기 위해 사용한다. 예를 들어 학생의 이름, 학번, 성적처럼 서로 다른 자료형의 정보를 하나의 자료형으로 만들어 효율적으로 관리할 수 있다.
- 구조체 정의는 구조체에 포함될 멤버와 자료형을 지정하여 새로운 자료형을 만드는 것이고, 구조체 변수 선언은 정의된 구조체 자료형을 이용하여 실제 데이터를 저장할 변수를 만드는 것이다.
# 실습과제2
- `struct Student`
  - 학번, 이름, 주소를 멤버로 가지는 구조체를 정의한다.

- `int number;`
  - 학번을 저장할 정수형 변수를 선언한다.

- `char name[50];`, `char address[100];`
  - 이름과 주소를 저장할 문자형 배열을 선언한다.

- `struct Student student;`
  - Student 구조체를 사용하는 변수 student를 선언한다.

- `scanf("%d", &student.number);`
  - 키보드로 입력받은 학번을 구조체 멤버 변수에 저장한다.

- `getchar();`
  - 학번 입력 후 버퍼에 남아 있는 줄바꿈 문자(\n)를 제거한다.

- `fgets(student.name, sizeof(student.name), stdin);`
  - 공백을 포함하여 이름을 입력받는다.

- `fgets(student.address, sizeof(student.address), stdin);`
  - 공백을 포함하여 주소를 입력받는다.

- `strcspn(student.name, "\n")`
  - 문자열에 포함된 줄바꿈 문자(\n)의 위치를 찾는다.

- `student.name[strcspn(student.name, "\n")] = '\0';`
  - 이름 문자열 끝의 줄바꿈 문자를 널 문자로 바꾼다.

- `printf()`
  - 구조체에 저장된 학번, 이름, 주소를 각각 화면에 출력한다.

- `return 0;`
  - 프로그램을 정상적으로 종료한다.
# 실습과제3
- `struct Car`
  - 자동차 모델, 번호판, 주행거리를 멤버로 가지는 구조체를 정의한다.

- `char model[50];`
  - 자동차 모델명을 저장할 문자형 배열을 선언한다.

- `char number[20];`
  - 자동차 번호판을 저장할 문자형 배열을 선언한다.

- `int distance;`
  - 자동차 주행거리를 저장할 정수형 변수를 선언한다.

- `struct Car car;`
  - Car 구조체를 사용하는 변수 car를 선언한다.

- `fgets(car.model, sizeof(car.model), stdin);`
  - 공백을 포함하여 자동차 모델명을 입력받는다.

- `fgets(car.number, sizeof(car.number), stdin);`
  - 자동차 번호판을 입력받는다.

- `strcspn(car.model, "\n")`
  - 모델명에 포함된 줄바꿈 문자(\n)의 위치를 찾는다.

- `car.model[strcspn(car.model, "\n")] = '\0';`
  - 모델명 끝의 줄바꿈 문자를 널 문자로 바꾼다.

- `scanf("%d", &car.distance);`
  - 자동차 주행거리를 입력받아 구조체 멤버 변수에 저장한다.

- `printf()`
  - 구조체에 저장된 모델, 번호판, 주행거리를 각각 화면에 출력한다.

- `return 0;`
  - 프로그램을 정상적으로 종료한다.

# 실습과제4
- `struct Point`
  - 2차원 좌표의 x값과 y값을 저장하는 구조체를 정의한다.

- `struct Rectangle`
  - 사각형의 좌측상단과 우측하단 좌표를 멤버로 가지는 구조체를 정의한다.

- `struct Point leftTop;`, `struct Point rightBottom;`
  - 각각 사각형의 좌측상단과 우측하단 좌표를 저장한다.

- `struct Rectangle rect;`
  - Rectangle 구조체를 사용하는 변수 rect를 선언한다.

- `scanf("%d %d", &rect.leftTop.x, &rect.leftTop.y);`
  - 좌측상단의 x좌표와 y좌표를 입력받아 저장한다.

- `scanf("%d %d", &rect.rightBottom.x, &rect.rightBottom.y);`
  - 우측하단의 x좌표와 y좌표를 입력받아 저장한다.

- `width = rect.rightBottom.x - rect.leftTop.x;`
  - 우측하단의 x좌표에서 좌측상단의 x좌표를 빼서 사각형의 폭을 계산한다.

- `height = rect.rightBottom.y - rect.leftTop.y;`
  - 우측하단의 y좌표에서 좌측상단의 y좌표를 빼서 사각형의 높이를 계산한다.

- `printf()`
  - 계산된 사각형의 폭과 높이를 화면에 출력한다.

- `return 0;`
  - 프로그램을 정상적으로 종료한다.
# 실습과제5
- `struct point`
  - x와 y를 멤버로 가지는 2차원 좌표 구조체를 정의한다.

- `struct point p1 = {10, 10}, p2 = {20, 20};`
  - point 구조체 변수 p1과 p2를 선언하고 각각 (10, 10), (20, 20)으로 초기화한다.

- `int temp;`
  - 두 변수의 값을 교환할 때 임시로 저장할 정수형 변수를 선언한다.

- `printf()`
  - 값 교환 전 두 구조체 변수의 좌표를 화면에 출력한다.

- `temp = p1.x;`
  - p1의 x값을 임시 변수 temp에 저장한다.

- `p1.x = p2.x;`
  - p2의 x값을 p1의 x값에 저장한다.

- `p2.x = temp;`
  - 임시 변수에 저장했던 기존 p1의 x값을 p2에 저장하여 x값을 교환한다.

- `temp = p1.y;`
  - p1의 y값을 임시 변수 temp에 저장한다.

- `p1.y = p2.y;`, `p2.y = temp;`
  - 위와 같은 방법으로 두 구조체 변수의 y값을 교환한다.

- `printf()`
  - 값 교환 후 두 구조체 변수의 좌표를 화면에 출력한다.

- `return 0;`
  - 프로그램을 정상적으로 종료한다.
