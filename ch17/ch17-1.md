`int* ptrarr[3] = { &num1, &num2, &num3 };`

각 변수의 주소를 포인터 배열 `ptrarr`에 저장한다.

`max = *(dptrarr[0]);`

첫 번째 배열의 값을 가져와 최댓값의 초기값으로 설정한다.

`if (max < *(dptrarr[i]))`

현재 최댓값과 배열의 값을 비교하여 더 큰 값을 찾는다.

`max = *(dptrarr[i]);`

현재 값이 더 크면 `max`에 해당 값을 저장한다.

`max = Max(ptrarr, 3);`

`Max()` 함수를 호출하여 포인터 배열의 최댓값을 받아 `max`에 저장한다.

`printf("최댓값:%d\n", max);`

구한 최댓값을 화면에 출력한다.

# 실습과제4

`#include <stdio.h>`

printf() 함수를 사용하기 위해 표준 입출력 헤더 파일을 포함한다.


`void MaxAndMin(int* arr, int size, int** maxPtr, int** minPtr);`

배열의 최댓값과 최솟값을 찾아 포인터에 저장하는 함수의 원형을 선언한다.


`int* maxPtr;`

최댓값이 들어 있는 배열 요소의 주소를 저장할 포인터 변수를 선언한다.


`int* minPtr;`

최솟값이 들어 있는 배열 요소의 주소를 저장할 포인터 변수를 선언한다.


`int arr[5] = { 10, 30, 20, 50, 15 };`

5개의 정수를 저장하는 배열을 만들고 각각 10, 30, 20, 50, 15를 저장한다.


메모리에는 다음과 같이 저장된다고 생각할 수 있다.

        arr
        ↓
주소    값
1000   [10]
1004   [30]
1008   [20]
1012   [50]
1016   [15]


`MaxAndMin(arr, 5, &maxPtr, &minPtr);`

배열의 시작 주소와 배열의 크기를 전달하고, `maxPtr`과 `minPtr`의 주소도 함수에 전달한다.


함수를 호출하면 메모리는 다음과 같이 연결된다.

maxPtr                         minPtr
  ↓                              ↓
[  ?  ]                        [  ?  ]
  ↑                              ↑
&maxPtr                        &minPtr


`void MaxAndMin(int* arr, int size, int** maxPtr, int** minPtr)`

함수에서 `arr`은 배열의 시작 주소를 저장하고, `maxPtr`과 `minPtr`은 각각 `maxPtr`, `minPtr`의 주소를 저장한다.


`*maxPtr = &arr[0];`

`maxPtr`이 가리키는 곳에 배열의 첫 번째 요소 주소를 저장한다.


maxPtr
  ↓
[1000]
   ↓
arr[0] = 10


`*minPtr = &arr[0];`

`minPtr`도 처음에는 배열의 첫 번째 요소 주소를 저장한다.


maxPtr                    minPtr
  ↓                         ↓
[1000]                    [1000]
   ↓                         ↓
 [10]  [30]  [20]  [50]  [15]


`for (int i = 1; i < size; i++)`

두 번째 배열 요소부터 마지막 요소까지 최댓값과 최솟값을 비교한다.


`if (**maxPtr < arr[i])`

`**maxPtr`은 `maxPtr`이 가리키는 주소에 있는 실제 값을 의미한다.

예를 들어 처음에는 `**maxPtr`이 10이므로 10과 현재 배열 값을 비교한다.


`*maxPtr = &arr[i];`

현재 배열의 값이 더 크면 `maxPtr`이 해당 배열 요소의 주소를 가리키도록 변경한다.


i = 1일 때

maxPtr
  ↓
[1004]
   ↓
  30

따라서 현재 최댓값은 30이 된다.


i = 2일 때

30과 20을 비교하므로 최댓값은 그대로 30이다.


i = 3일 때

30과 50을 비교하므로 `maxPtr`이 50의 주소를 가리키게 된다.


maxPtr
  ↓
[1012]
   ↓
  50


`if (**minPtr > arr[i])`

`**minPtr`의 현재 값과 배열의 값을 비교하여 더 작은 값을 찾는다.


`*minPtr = &arr[i];`

현재 배열의 값이 더 작으면 `minPtr`이 해당 배열 요소의 주소를 가리키도록 변경한다.


이 문제에서는 처음 값인 10이 가장 작기 때문에 `minPtr`은 계속 10을 가리킨다.


최종 메모리 상태

maxPtr                         minPtr
  ↓                              ↓
[1012]                         [1000]
   ↓                              ↓
┌────┬────┬────┬────┬────┐
│ 10 │ 30 │ 20 │ 50 │ 15 │
└────┴────┴────┴────┴────┘
  ↑                ↑
1000             1012


`printf("최댓값: %d\n", **maxPtr);`

`maxPtr`이 가리키는 주소의 값을 두 번 역참조하여 최댓값 50을 출력한다.


`printf("최솟값: %d\n", **minPtr);`

`minPtr`이 가리키는 주소의 값을 두 번 역참조하여 최솟값 10을 출력한다.


`return 0;`

프로그램을 정상적으로 종료한다.
