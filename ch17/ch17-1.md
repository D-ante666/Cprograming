# 실습과제2

`int* ptrarr[3] = { &num1, &num2, &num3 };`

각 변수의 주소를 포인터 배열 `ptrarr`에 저장한다.

`max = *(dptrarr[0]);`

첫 번째 배열의 값을 가져와 최댓값의 초기값으로 설정한다.

`if (max < *(dptrarr[i]))`

현재 최댓값과 배열의 값을 비교하여 더 큰 값을 찾는다.

`max = *(dptrarr[i]);`

현재 값이 더 크면 `max`에 해당 값을 저장한다.

`max = Max(ptrarr, 3);`

`Max()` 함수를 호출하여 포인터 배열의 최댓값을 받아 `max`에 저장한다.

`printf("최댓값:%d\n", max);`

구한 최댓값을 화면에 출력한다.

`void prn_str(char** ptrarr, int count);`

문자열 포인터 배열과 배열의 크기를 전달받는 함수를 선언한다.

`count = sizeof(ptrarr) / sizeof(ptrarr[0]);`

포인터 배열에 저장된 문자열의 개수를 계산한다.

`prn_str(ptrarr, count);`

문자열 포인터 배열과 문자열의 개수를 함수에 전달한다.

`for (int i = 0; i < count; i++)`

`printf("%s\n", ptrarr[i]);`

# 실습과제4

`int* maxPtr;`

최댓값이 저장된 배열 요소의 주소를 저장할 포인터를 선언한다.

`int* minPtr;`

최솟값이 저장된 배열 요소의 주소를 저장할 포인터를 선언한다.

`int arr[5] = { 10, 30, 20, 50, 15 };`

5개의 정수를 배열에 저장한다.

메모리 상태는 다음과 같이 표현할 수 있다.

주소 | 값
--- | ---
1000 | 10
1004 | 30
1008 | 20
1012 | 50
1016 | 15

`MaxAndMin(arr, 5, &maxPtr, &minPtr);`

배열의 주소와 크기, `maxPtr`과 `minPtr`의 주소를 함수에 전달한다.

`void MaxAndMin(int* arr, int size, int** maxPtr, int** minPtr)`

`maxPtr`과 `minPtr`의 주소를 받기 위해 이중 포인터를 사용한다.

`*maxPtr = &arr[0];`

처음에는 `maxPtr`이 배열의 첫 번째 요소인 10의 주소를 가리키도록 한다.

`*minPtr = &arr[0];`

처음에는 `minPtr`도 배열의 첫 번째 요소인 10의 주소를 가리키도록 한다.

초기 메모리 상태

maxPtr → 1000 → 10
minPtr → 1000 → 10

`if (**maxPtr < arr[i])`

현재 `maxPtr`이 가리키는 값과 배열의 값을 비교하여 더 큰 값을 찾는다.

`*maxPtr = &arr[i];`

더 큰 값이 발견되면 `maxPtr`이 해당 배열 요소의 주소를 가리키도록 변경한다.

50을 찾은 후의 상태

maxPtr → 1012 → 50
minPtr → 1000 → 10

`if (**minPtr > arr[i])`

현재 `minPtr`이 가리키는 값과 배열의 값을 비교하여 더 작은 값을 찾는다.

`*minPtr = &arr[i];`

더 작은 값이 발견되면 `minPtr`이 해당 배열 요소의 주소를 가리키도록 변경한다.

이 배열에서는 10이 가장 작기 때문에 `minPtr`은 10의 주소를 계속 가리킨다.

최종 메모리 상태

maxPtr → 1012 → 50
minPtr → 1000 → 10

`printf("최댓값: %d\n", *maxPtr);`

`maxPtr`이 가리키는 주소에 저장된 최댓값 50을 출력한다.

`printf("최솟값: %d\n", *minPtr);`

`minPtr`이 가리키는 주소에 저장된 최솟값 10을 출력한다.
