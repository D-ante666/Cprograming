# 실습과제2

`int* ptrarr[3] = { &num1, &num2, &num3 };`

각 변수의 주소를 포인터 배열 `ptrarr`에 저장한다.

`max = *(dptrarr[0]);`

첫 번째 배열의 값을 가져와 최댓값의 초기값으로 설정한다.

`if (max < *(dptrarr[i]))`

현재 최댓값과 배열의 값을 비교하여 더 큰 값을 찾는다.

`max = *(dptrarr[i]);`

현재 값이 더 크면 `max`에 해당 값을 저장한다.

`max = Max(ptrarr, 3);`

`Max()` 함수를 호출하여 포인터 배열의 최댓값을 받아 `max`에 저장한다.

`printf("최댓값:%d\n", max);`

구한 최댓값을 화면에 출력한다.

# 실습과제3

`void prn_str(char** ptrarr, int count);`

문자열 포인터 배열과 배열의 크기를 전달받는 함수를 선언한다.

`count = sizeof(ptrarr) / sizeof(ptrarr[0]);`

포인터 배열에 저장된 문자열의 개수를 계산한다.

`prn_str(ptrarr, count);`

문자열 포인터 배열과 문자열의 개수를 함수에 전달한다.

`for (int i = 0; i < count; i++)`

배열에 저장된 문자열을 처음부터 끝까지 반복해서 확인한다.

`printf("%s\n", ptrarr[i]);`

`ptrarr[i]`에 저장된 문자열을 하나씩 출력한다.
