# 실습과제2
# 소스코드 설명

```c
void Max(int* parr);
```

* 정수형 배열의 주소를 전달받아 최대값을 구하는 `Max` 함수를 선언한다.

```c
int i, arr[5];
```

* 정수 5개를 저장할 배열 `arr`과 반복문에 사용할 변수 `i`를 선언한다.

```c
for (i = 0; i < 5; i++) {
```

* 배열에 정수 5개를 입력받기 위해 5번 반복한다.

```c
scanf("%d", &arr[i]);
```

* 입력받은 정수를 배열 `arr`의 현재 위치에 저장한다.

```c
Max(arr);
```

* 배열 `arr`의 시작 주소를 `Max` 함수에 전달한다.

```c
void Max(int* parr) {
```

* 배열의 주소를 매개변수 `parr`로 전달받아 최대값을 구하는 함수를 정의한다.

```c
max = parr[0];
```

* 배열의 첫 번째 값을 처음 최대값으로 설정한다.

```c
for (i = 1; i < 5; i++) {
```

* 두 번째 원소부터 마지막 원소까지 차례대로 비교한다.

```c
if (max < parr[i]) max = parr[i];
```

* 현재 최대값보다 큰 값이 발견되면 그 값을 새로운 최대값으로 저장한다.

```c
printf("최대값은: %d", max);
```

* 배열에서 구한 최대값을 출력한다.

int i, data[5];

# 실습과제4
# 소스코드 설명

```c
void Divide(double* pnum, int* inum, double* dnum);
```

* 실수의 주소를 전달받아 정수 부분과 소수 부분을 나누는 `Divide` 함수를 선언한다.

```c
double num = 0;
int inum = 0;
double dnum = 0;
```

* 입력받을 실수 `num`, 정수 부분을 저장할 `inum`, 소수 부분을 저장할 `dnum`을 선언한다.

```c
scanf("%lf", &num);
```

* 사용자에게 입력받은 실수를 `num`에 저장한다.

```c
Divide(&num, &inum, &dnum);
```

* `num`, `inum`, `dnum`의 주소를 `Divide` 함수에 전달하여 정수 부분과 소수 부분을 구한다.

```c
printf("정수부분: %d, 소수부분: %f\n", inum, dnum);
```

* 계산된 정수 부분과 소수 부분을 출력한다.

```c
void Divide(double* pnum, int* inum, double* dnum) {
```

* 실수의 주소와 정수·소수 부분을 저장할 변수들의 주소를 전달받는 `Divide` 함수를 정의한다.

```c
*inum = (int)(*pnum);
```

* 실수를 정수형으로 형변환하여 정수 부분을 `inum`에 저장한다.

```c
*dnum = (*pnum) - (int)(*pnum);
```

* 원래 실수에서 정수 부분을 빼서 소수 부분을 `dnum`에 저장한다.
