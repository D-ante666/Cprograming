# 실습과제 1

- 인자는 함수를 호출할 때 실제로 넘겨주는 값(또는 변수)이고, 매개변수는 함수 정의부에서 그 값을 받기 위해 선언해 놓은 변수이다. 즉 호출하는 쪽에서 주는 것이 인자, 함수 안에서 받는 것이 매개변수이다.

- 1. 매개변수에 인자값이 복사되어 저장된다.
  2. 함수 호출이 끝난 뒤 돌아갈 위치(복귀 주소)가 스택에 저장된다.

- 함수 호출 시 인자의 값이 매개변수에 복사되어 전달되기 때문에, 함수 안에서 매개변수의 값을 바꿔도 원래 호출한 쪽의 변수 값은 전혀 바뀌지 않는다. 즉 함수 안에서의 결과를 호출한 쪽으로 돌려줄 수 없다.

-  함수 안에서 값을 변경한 결과를 호출한 쪽의 원본 변수에도 반영해야 할 때 필요하다. 예를 들어 두 변수의 값을 교환(swap)하거나, 하나의 함수에서 여러 개의 값을 동시에 변경해서 돌려줘야 할 때 사용한다.

# 실습과제 2

기존 코드가 원하는 대로 동작하지 않는 이유는 `add2` 함수가 **값에 의한 호출**을 사용하기 때문이다.

`add2(number)`를 호출하면 `number`에 저장된 값(15)이 복사되어 매개변수 `value`에 저장된다. 이때 `value`는 `number`와는 별개의, 함수 안에서만 존재하는 새로운 메모리 공간이다. 함수 안에서 `value += 2`를 해도 이건 `value`라는 별도 공간의 값만 바뀌는 것이고, 함수가 끝나면 `value`는 메모리에서 사라진다. `number`가 저장된 메모리 공간은 처음부터 끝까지 전혀 건드려지지 않기 때문에 결과가 그대로 15로 출력되는 것이다.

원하는 결과가 나오려면 `number`의 주소를 넘겨줘서, 함수 안에서 그 주소가 가리키는 메모리에 직접 접근해 값을 바꿔야 한다. (주소에 의한 호출)
