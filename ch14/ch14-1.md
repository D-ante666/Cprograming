# 실습과제 1

- 인자는 함수를 호출할 때 실제로 넘겨주는 값(또는 변수)이고, 매개변수는 함수 정의부에서 그 값을 받기 위해 선언해 놓은 변수이다. 즉 호출하는 쪽에서 주는 것이 인자, 함수 안에서 받는 것이 매개변수이다.

- 1. 매개변수에 인자값이 복사되어 저장된다.
  2. 함수 호출이 끝난 뒤 돌아갈 위치(복귀 주소)가 스택에 저장된다.

- 함수 호출 시 인자의 값이 매개변수에 복사되어 전달되기 때문에, 함수 안에서 매개변수의 값을 바꿔도 원래 호출한 쪽의 변수 값은 전혀 바뀌지 않는다. 즉 함수 안에서의 결과를 호출한 쪽으로 돌려줄 수 없다.

-  함수 안에서 값을 변경한 결과를 호출한 쪽의 원본 변수에도 반영해야 할 때 필요하다. 예를 들어 두 변수의 값을 교환(swap)하거나, 하나의 함수에서 여러 개의 값을 동시에 변경해서 돌려줘야 할 때 사용한다.

# 실습과제 2

기존 코드가 원하는 대로 동작하지 않는 이유는 `add2` 함수가 **값에 의한 호출**을 사용하기 때문이다.

`add2(number)`를 호출하면 `number`에 저장된 값(15)이 복사되어 매개변수 `value`에 저장된다. 이때 `value`는 `number`와는 별개의, 함수 안에서만 존재하는 새로운 메모리 공간이다. 함수 안에서 `value += 2`를 해도 이건 `value`라는 별도 공간의 값만 바뀌는 것이고, 함수가 끝나면 `value`는 메모리에서 사라진다. `number`가 저장된 메모리 공간은 처음부터 끝까지 전혀 건드려지지 않기 때문에 결과가 그대로 15로 출력되는 것이다.

원하는 결과가 나오려면 `number`의 주소를 넘겨줘서, 함수 안에서 그 주소가 가리키는 메모리에 직접 접근해 값을 바꿔야 한다. (주소에 의한 호출)

# 실습과제4

`void swap(int* px, int* py);`
- `swap` 함수의 원형을 선언한다.
- 두 정수의 주소를 전달받아 두 변수의 값을 서로 교환하는 함수이다.

`int x, y, z;`
- 세 개의 정수를 저장할 `x`, `y`, `z` 변수를 선언한다.

`scanf("%d", &x);`
- 사용자에게 정수를 입력받아 `x`에 저장한다.

`scanf("%d", &y);`
- 사용자에게 정수를 입력받아 `y`에 저장한다.

`scanf("%d", &z);`
- 사용자에게 정수를 입력받아 `z`에 저장한다.

`printf("swap함수 호출 전 x=%d, y=%d, z=%d\n", x, y, z);`
- `swap` 함수를 호출하기 전 `x`, `y`, `z`의 값을 출력한다.

`swap(&x, &y);`
- `x`와 `y`의 주소를 `swap` 함수에 전달한다.
- `x`와 `y`의 값을 서로 교환한다.

`swap(&y, &z);`
- `y`와 `z`의 주소를 `swap` 함수에 전달한다.
- `y`와 `z`의 값을 서로 교환한다.

`void swap(int* px, int* py)`
- 두 변수의 주소를 `px`, `py` 포인터에 전달받는다.
- 포인터를 이용하여 원래 변수의 값을 직접 변경한다.

`int tmp;`
- 값을 임시로 저장하기 위한 `tmp` 변수를 선언한다.

`tmp = *px;`
- `px`가 가리키는 값을 `tmp`에 저장한다.

`*px = *py;`
- `py`가 가리키는 값을 `px`가 가리키는 변수에 저장한다.

`*py = tmp;`
- `tmp`에 저장해 둔 원래 `px`의 값을 `py`가 가리키는 변수에 저장한다.
- 이를 통해 두 변수의 값이 서로 교환된다.

`printf("swap함수 호출 후 x=%d, y=%d, z=%d\n", x, y, z);`
- `swap` 함수를 호출한 후 `x`, `y`, `z`의 값을 출력한다.

# 실습과제5

`int SquareByValue(int num);`
- `SquareByValue` 함수의 원형을 선언한다.
- 정수 값을 전달받아 100배한 값을 반환하는 함수이다.

`void SquareByReference(int* num);`
- `SquareByReference` 함수의 원형을 선언한다.
- 정수 변수의 주소를 전달받아 해당 변수의 값을 직접 100배로 변경하는 함수이다.

`int num;`
- 사용자에게 입력받은 정수를 저장할 `num` 변수를 선언한다.

`scanf("%d", &num);`
- 사용자에게 정수를 입력받아 `num`에 저장한다.

`printf("Call-by-value 결과: %d\n", SquareByValue(num));`
- `num`의 값을 `SquareByValue` 함수에 전달한다.
- 함수에서 100배한 값을 반환받아 출력한다.
- Call-by-value 방식에서는 원래 `num`의 값은 변경되지 않는다.

`SquareByReference(&num);`
- `num`의 주소를 `SquareByReference` 함수에 전달한다.
- Call-by-reference 방식에서는 포인터를 이용하여 원래 `num`의 값을 직접 변경한다.

`printf("Call-by-reference 결과: %d\n", num);`
- 100배로 변경된 `num`의 값을 출력한다.

`int SquareByValue(int num)`
- 전달받은 값으로 계산한 결과를 반환하는 Call-by-value 방식의 함수이다.

`return num * 100;`
- 전달받은 `num`의 값을 100배하여 반환한다.

`void SquareByReference(int* num)`
- `num`의 주소를 포인터로 전달받는 Call-by-reference 방식의 함수이다.

`*num = *num * 100;`
- `num`이 가리키는 변수의 값을 100배하여 원래 변수에 저장한다.

`Call-by-value`
- 변수의 값을 복사해서 함수에 전달한다.
- 함수에서 값을 변경해도 원래 변수에는 영향을 주지 않는다.

`Call-by-reference`
- 변수의 주소를 함수에 전달한다.
- 포인터를 이용하여 원래 변수의 값을 직접 변경할 수 있다.

`Call-by-value`는 계산한 값을 반환해야 원래 변수에 사용할 수 있고, `Call-by-reference`는 포인터를 이용해 원래 변수 자체를 변경할 수 있다는 차이가 있다.
