# 실습과제 1

| 수식 | 결과값 | 결과값의 자료형 |
|---|---:|---|
| &ch | 100 | char* |
| &in | 101 | int* |
| &db | 105 | double* |
| *&ch | A | char |
| *&in | 10 | int |
| *&db | 3.4 | double |

& 연산자는 변수의 주소를 반환하고, * 연산자는 포인터 또는 주소가 가리키는 곳의 값을 반환한다.

따라서 *&ch는 *(&ch)로 해석되며, 먼저 &ch를 통해 ch의 주소를 구한 후 * 연산자를 통해 그 주소에 저장된 값인 A를 가져온다.

마찬가지로 *&in은 10, *&db는 3.4가 된다.

# 실습과제 3

## ①번 라인에서 강제형변환이 사용된 이유

①번 라인의 코드는 다음과 같다.

int* ptr = (int*)125;

여기에서 (int*)는 강제형변환이다.

정수 125를 int형 포인터로 변환하여 ptr에 저장하기 위해 사용되었다.

즉, 125라는 정수값을 int형 데이터가 저장되어 있는 메모리 주소로 해석하도록 만드는 것이다.

## 오류가 발생하는 이유

다음 코드에서 오류가 발생한다.

*ptr = 10;

ptr에는 실제 변수의 주소가 아니라 정수 125를 주소로 변환한 값이 저장되어 있다.

따라서 *ptr을 사용하면 125번 메모리 주소에 접근하여 10을 저장하려고 한다.

하지만 125번 주소가 프로그램에서 접근할 수 있는 유효한 메모리 영역이라는 보장이 없기 때문에 잘못된 메모리 접근이 발생하고 프로그램이 중단된다.

따라서 포인터를 사용할 때는 실제로 접근할 수 있는 변수의 주소를 저장해야 한다.

# 소스코드 설명

- 프로그램의 실행이 시작되는 main 함수를 정의한다.


```c
int sum;
```
- 두 정수의 합을 저장할 int형 변수 sum을 선언한다.

```c
int *pa = &a;
```
- 포인터 변수 pa를 선언하고 변수 a의 주소를 저장한다.

```c
int *pb = &b;
```
- 포인터 변수 pb를 선언하고 변수 b의 주소를 저장한다.

```c
int *psum = &sum;
```
- 포인터 변수 psum을 선언하고 변수 sum의 주소를 저장한다.

```c
*psum = *pa + *pb;
```

```c
printf("두 정수의 합 : %d\n", *psum);
```
- 포인터 psum을 이용하여 sum의 값을 간접 참조하고 결과를 출력한다.

# 실습과제 5
문제2번 변형: int형 변수 num1과 num2를 선언하고 각각 30과 50으로 초기화하시오. 포인터 변수 ptr1과 ptr2를 선언하여 각각 num1과 num2를 가리키게 하시오. 포인터를 이용하여 num1의 값을 20 증가시키고 num2의 값을 10 감소시키시오. 이후 두 포인터가 가리키는 대상을 서로 바꾸시오. 즉, ptr1이 num2를 가리키고 ptr2가 num1을 가리키도록 하시오. 마지막으로 ptr1이 가리키는 값을 출력하시오.
# 소스코드 설명
```c
int main(void)
```
- 프로그램의 실행이 시작되는 main 함수를 정의한다.
```c
int num1 = 30, num2 = 50;
```
- int형 변수 num1과 num2를 선언하고 각각 30과 50으로 초기화한다.

```c
int *ptr1 = &num1;
```
- 포인터 변수 ptr1을 선언하고 num1의 주소를 저장하여 num1을 가리키게 한다.

```c
int *ptr2 = &num2;
```
- 포인터 변수 ptr2를 선언하고 num2의 주소를 저장하여 num2를 가리키게 한다.

```c
int *temp;
```
- 포인터의 주소를 임시로 저장하기 위한 포인터 변수 temp를 선언한다.

```c
*ptr1 += 20;
```
- ptr1이 가리키는 num1의 값을 20 증가시킨다.

```c
*ptr2 -= 10;
```
- ptr2가 가리키는 num2의 값을 10 감소시킨다.

```c
temp = ptr1;
```
- ptr1이 가지고 있는 주소를 temp에 임시로 저장한다.

```c
ptr1 = ptr2;
```
- ptr2가 가지고 있던 주소를 ptr1에 저장하여 ptr1이 num2를 가리키게 한다.

```c
ptr2 = temp;
```
- temp에 저장해 둔 원래 ptr1의 주소를 ptr2에 저장하여 ptr2가 num1을 가리키게 한다.

```c
printf("ptr1이 가리키는 값 : %d\n", *ptr1);
```
- ptr1이 가리키는 num2의 값을 간접 참조하여 출력한다.
