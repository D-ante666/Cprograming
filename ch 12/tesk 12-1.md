- 포인터(포인터 변수)는 다른 변수의 메모리 주소를 저장하는 변수
- 포인터의 자료형은 저장할 변수의 자료형에 결정된다
- int에는 저장이 안 된다. 오류가 난다

# 실습과제 4
# 소스코드 설명

```
char a = 'A';
```
- char형 변수 a에 문자 'A'를 저장한다.

```
int b = 36;
```
- int형 변수 b에 정수 36을 저장한다.

```
double c = 3.141592;
```
- double형 변수 c에 실수 3.141592를 저장한다.

```
printf("char형 변수 a의 주소: %u\n", &a);
```
- char형 변수 a의 메모리 주소를 출력한다.

```
printf("int형 변수 b의 주소: %u\n", &b);
```
- int형 변수 b의 메모리 주소를 출력한다.

```
printf("double 형 변수 c의 주소: %u\n", &c);
```
- double형 변수 c의 메모리 주소를 출력한다.
