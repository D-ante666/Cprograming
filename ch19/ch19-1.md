# 실습과제 1

### 1. 함수 선언, 호출, 정의를 각각 설명하라

- 함수 선언 : 함수의 반환형, 함수명, 매개변수의 자료형 등을 미리 알려주는 것이다.
- 함수 호출 : 선언된 함수를 실제로 사용하는 것이다.
- 함수 정의 : 함수가 실제로 수행할 작업을 작성하는 것이다.


### 2. 함수의 자료형은?

함수의 자료형은 반환형과 매개변수의 자료형으로 정의된다.

예를 들어,
int sum(int a, int b)에서 함수의 자료형은int(int, int)이다.


### 3. 함수명의 자료형은?

함수명의 자료형은 함수에 대한 포인터 자료형으로 나타낼 수 있다.

예를 들어,int sum(int a, int b)에서 sum의 자료형은int (*)(int, int)이다.


### 4. void 포인터의 용도는?

void 포인터는 자료형이 정해지지 않은 포인터이다.
따라서 여러 종류의 자료형을 가리킬 수 있다.


### 5. void 포인터에 간접참조 연산을 적용할 때 주의할 점은?

void 포인터는 가리키는 자료형을 알 수 없기 때문에
그 상태에서는 간접참조 연산을 할 수 없다.
따라서 원하는 자료형의 포인터로 형변환한 후 간접참조해야 한다.


### 6. 강제형변환과 자동형변환을 설명하시오

- 강제형변환 : 프로그래머가 직접 자료형을 지정하여 변환하는 것이다.
  예) (double)10

- 자동형변환 : 컴파일러가 자료형에 맞게 자동으로 변환하는 것이다.
  예) int a = 10;
      double b = a;

# 실습과제3

```c
int add(int a, int b);
int sub(int a, int b);
int mul(int a, int b);
int div(int a, int b);
```

덧셈, 뺄셈, 곱셈, 나눗셈을 수행하는 함수의 원형을 선언한다.

```c
int calculate(int a, int b, int (*fp)(int, int));
```

두 정수와 함수 포인터를 전달받는 함수를 선언한다.

```c
int (*fp)(int, int);
```

두 개의 정수를 전달받고 정수를 반환하는 함수를 가리키는 포인터를 선언한다.

```c
scanf("%d", &op);
scanf("%d %d", &a, &b);
```

사용자가 선택한 연산 번호와 두 개의 정수를 입력받는다.

```c
if (op == 1)
    fp = add;
else if (op == 2)
    fp = sub;
else if (op == 3)
    fp = mul;
else if (op == 4)
    fp = div;
```

선택한 연산에 따라 함수 포인터에 해당 함수의 주소를 저장한다.

```c
printf("결과값: %d\n", calculate(a, b, fp));
```

두 정수와 함수 포인터를 전달하여 계산한 결과를 출력한다.

```c
int calculate(int a, int b, int (*fp)(int, int)) {
    return fp(a, b);
}
```

전달받은 함수 포인터를 이용하여 해당 연산 함수를 호출하고 결과를 반환한다.

```c
return a + b;
return a - b;
return a * b;
return a / b;
```

각각 두 정수의 덧셈, 뺄셈, 곱셈, 나눗셈 결과를 반환한다.
