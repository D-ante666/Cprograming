# 실습과제 1

### 1. 함수 선언, 호출, 정의를 각각 설명하라

- 함수 선언 : 함수의 반환형, 함수명, 매개변수의 자료형 등을 미리 알려주는 것이다.
- 함수 호출 : 선언된 함수를 실제로 사용하는 것이다.
- 함수 정의 : 함수가 실제로 수행할 작업을 작성하는 것이다.


### 2. 함수의 자료형은?

함수의 자료형은 반환형과 매개변수의 자료형으로 정의된다.

예를 들어,
int sum(int a, int b)에서 함수의 자료형은int(int, int)이다.


### 3. 함수명의 자료형은?

함수명의 자료형은 함수에 대한 포인터 자료형으로 나타낼 수 있다.

예를 들어,int sum(int a, int b)에서 sum의 자료형은int (*)(int, int)이다.


### 4. void 포인터의 용도는?

void 포인터는 자료형이 정해지지 않은 포인터이다.
따라서 여러 종류의 자료형을 가리킬 수 있다.


### 5. void 포인터에 간접참조 연산을 적용할 때 주의할 점은?

void 포인터는 가리키는 자료형을 알 수 없기 때문에
그 상태에서는 간접참조 연산을 할 수 없다.
따라서 원하는 자료형의 포인터로 형변환한 후 간접참조해야 한다.


### 6. 강제형변환과 자동형변환을 설명하시오

- 강제형변환 : 프로그래머가 직접 자료형을 지정하여 변환하는 것이다.
  예) (double)10

- 자동형변환 : 컴파일러가 자료형에 맞게 자동으로 변환하는 것이다.
  예) int a = 10;
      double b = a;
