# 실습과제1
- `char str[1000] = "";` : 입력받은 문자열을 연결하여 저장할 배열을 선언하고 빈 문자열로 초기화한다.
- `char input[100];` : 사용자에게 입력받을 문자열을 저장할 배열을 선언한다.
- `while (1)` : 사용자가 `quit`을 입력할 때까지 반복한다.
- `scanf("%99s", input);` : 문자열을 입력받는다. 공백 전까지 입력받으므로 한 단어씩 입력한다.
- `strcmp(input, "quit") == 0` : 입력한 문자열이 `quit`과 같은지 비교한다. 같으면 `break`로 반복문을 종료한다.
- `strcat(str, input);` : 기존 문자열 뒤에 새로 입력받은 문자열을 연결한다.
- `strcat(str, " ");` : 단어 사이에 공백을 추가한다.
- `printf("입력된 문자열: %s\n", str);` : 지금까지 연결한 문자열을 출력한다.
