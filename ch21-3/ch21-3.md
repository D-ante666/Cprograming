# 실습과제1
- `char str[1000] = "";` : 입력받은 문자열을 연결하여 저장할 배열을 선언하고 빈 문자열로 초기화한다.
- `char input[100];` : 사용자에게 입력받을 문자열을 저장할 배열을 선언한다.
- `while (1)` : 사용자가 `quit`을 입력할 때까지 반복한다.
- `scanf("%99s", input);` : 문자열을 입력받는다. 공백 전까지 입력받으므로 한 단어씩 입력한다.
- `strcmp(input, "quit") == 0` : 입력한 문자열이 `quit`과 같은지 비교한다. 같으면 `break`로 반복문을 종료한다.
- `strcat(str, input);` : 기존 문자열 뒤에 새로 입력받은 문자열을 연결한다.
- `strcat(str, " ");` : 단어 사이에 공백을 추가한다.
- `printf("입력된 문자열: %s\n", str);` : 지금까지 연결한 문자열을 출력한다.

# 실습과제2
- `int my_strlen(const char *str);`
  - 문자열의 길이를 구하는 함수를 선언한다. `const`는 함수 안에서 문자열의 내용을 변경하지 않겠다는 의미이다.

- `void RemoveBSN(char *str);`
  - 문자열에 포함된 줄바꿈 문자 `\n`을 제거하는 함수를 선언한다.

- `char str[100];`
  - 사용자에게 입력받을 문자열을 저장할 문자 배열을 선언한다.

- `fgets(str, sizeof(str), stdin);`
  - 공백을 포함한 문자열을 입력받는다. 입력한 문자열 끝에 엔터로 인한 줄바꿈 문자 `\n`이 포함될 수 있다.

- `while (str[count] != '\0')`
  - 문자열의 끝을 나타내는 널 문자 `\0`을 만날 때까지 반복한다.

- `count++;`
  - 문자를 하나씩 확인하면서 문자열의 길이를 1씩 증가시킨다.

- `return count;`
  - 계산한 문자열의 길이를 반환한다. 이때 널 문자 `\0`은 길이에 포함하지 않지만, 줄바꿈 문자 `\n`은 포함한다.

- `int len = my_strlen(str);`
  - `my_strlen()` 함수를 호출하여 문자열의 길이를 구하고 `len`에 저장한다.

- `if (len > 0 && str[len - 1] == '\n')`
  - 문자열의 길이가 0보다 크고, 마지막 문자가 줄바꿈 문자 `\n`인지 확인한다. `&&`는 두 조건이 모두 참이어야 한다는 의미이다.

- `str[len - 1] = '\0';`
  - 마지막 줄바꿈 문자를 널 문자 `\0`으로 바꾸어 줄바꿈 문자를 제거한다.

- `printf("길이: %d, 내용: %s\n", my_strlen(str), str);`
  - `my_strlen()`으로 구한 문자열의 길이와 문자열의 내용을 출력한다. `RemoveBSN()` 호출 전에는 줄바꿈 문자가 길이에 포함될 수 있고, 호출 후에는 제거된 문자열의 길이를 출력한다.
