# 실습과제1
- `char str[1000] = "";` : 입력받은 문자열을 연결하여 저장할 배열을 선언하고 빈 문자열로 초기화한다.
- `char input[100];` : 사용자에게 입력받을 문자열을 저장할 배열을 선언한다.
- `while (1)` : 사용자가 `quit`을 입력할 때까지 반복한다.
- `scanf("%99s", input);` : 문자열을 입력받는다. 공백 전까지 입력받으므로 한 단어씩 입력한다.
- `strcmp(input, "quit") == 0` : 입력한 문자열이 `quit`과 같은지 비교한다. 같으면 `break`로 반복문을 종료한다.
- `strcat(str, input);` : 기존 문자열 뒤에 새로 입력받은 문자열을 연결한다.
- `strcat(str, " ");` : 단어 사이에 공백을 추가한다.
- `printf("입력된 문자열: %s\n", str);` : 지금까지 연결한 문자열을 출력한다.

# 실습과제2
- `int my_strlen(const char *str);`
  - 문자열의 길이를 구하는 함수를 선언한다. `const`는 함수 안에서 문자열의 내용을 변경하지 않겠다는 의미이다.

- `void RemoveBSN(char *str);`
  - 문자열에 포함된 줄바꿈 문자 `\n`을 제거하는 함수를 선언한다.

- `char str[100];`
  - 사용자에게 입력받을 문자열을 저장할 문자 배열을 선언한다.

- `fgets(str, sizeof(str), stdin);`
  - 공백을 포함한 문자열을 입력받는다. 입력한 문자열 끝에 엔터로 인한 줄바꿈 문자 `\n`이 포함될 수 있다.

- `while (str[count] != '\0')`
  - 문자열의 끝을 나타내는 널 문자 `\0`을 만날 때까지 반복한다.

- `count++;`
  - 문자를 하나씩 확인하면서 문자열의 길이를 1씩 증가시킨다.

- `return count;`
  - 계산한 문자열의 길이를 반환한다. 이때 널 문자 `\0`은 길이에 포함하지 않지만, 줄바꿈 문자 `\n`은 포함한다.

- `int len = my_strlen(str);`
  - `my_strlen()` 함수를 호출하여 문자열의 길이를 구하고 `len`에 저장한다.

- `if (len > 0 && str[len - 1] == '\n')`
  - 문자열의 길이가 0보다 크고, 마지막 문자가 줄바꿈 문자 `\n`인지 확인한다. `&&`는 두 조건이 모두 참이어야 한다는 의미이다.

- `str[len - 1] = '\0';`
  - 마지막 줄바꿈 문자를 널 문자 `\0`으로 바꾸어 줄바꿈 문자를 제거한다.

- `printf("길이: %d, 내용: %s\n", my_strlen(str), str);`
  - `my_strlen()`으로 구한 문자열의 길이와 문자열의 내용을 출력한다. `RemoveBSN()` 호출 전에는 줄바꿈 문자가 길이에 포함될 수 있고, 호출 후에는 제거된 문자열의 길이를 출력한다.

# 실습과제3
- `void my_strcpy(char *dest, const char *src);`
  - 원본 문자열을 목적지 문자열에 복사하는 함수를 선언한다.

- `char str1[20] = "1234567890";`
  - 복사할 원본 문자열을 저장하는 문자 배열을 선언하고 초기화한다.

- `char str2[20];`
  - 복사한 문자열을 저장할 목적지 배열을 선언한다.

- `my_strcpy(str2, str1);`
  - `str1`의 문자열을 `str2`에 복사하는 함수를 호출한다.

- `while (src[i] != '\0')`
  - 원본 문자열의 끝을 나타내는 널 문자 `\0`을 만날 때까지 반복한다.

- `dest[i] = src[i];`
  - 원본 문자열의 문자를 목적지 배열의 같은 위치에 복사한다.

- `i++;`
  - 다음 문자를 복사하기 위해 인덱스를 1 증가시킨다.

- `dest[i] = '\0';`
  - 복사가 끝난 위치에 널 문자를 저장하여 목적지 문자열의 끝을 표시한다.

- `puts(str2);`
  - 복사된 문자열을 출력하고 자동으로 줄바꿈한다.

# 실습과제4
- `void my_strcat(char *dest, const char *src);`
  - 원본 문자열을 목적지 문자열 뒤에 이어 붙이는 함수를 선언한다.

- `char str1[20] = "First~";`
  - 문자열을 이어 붙일 목적지 배열을 선언하고 초기화한다.

- `char str2[20] = "Second";`
  - 뒤에 이어 붙일 원본 문자열을 저장하는 배열을 선언한다.

- `my_strcat(str1, str2);`
  - `str2`의 문자열을 `str1`의 끝에 이어 붙이는 함수를 호출한다.

- `while (dest[i] != '\0')`
  - 목적지 문자열의 끝을 찾기 위해 널 문자 `\0`이 나올 때까지 반복한다.

- `while (src[j] != '\0')`
  - 원본 문자열의 끝에 도달할 때까지 문자를 하나씩 복사한다.

- `dest[i] = src[j];`
  - 원본 문자열의 문자를 목적지 문자열의 끝에 저장한다.

- `i++;`, `j++;`
  - 목적지와 원본 문자열의 다음 위치로 이동하기 위해 인덱스를 각각 1씩 증가시킨다.

- `dest[i] = '\0';`
  - 문자열을 모두 이어 붙인 뒤 마지막에 널 문자를 저장하여 문자열의 끝을 표시한다.

- `puts(str1);`
  - 이어 붙인 문자열 `First~Second`를 출력하고 자동으로 줄바꿈한다.

# 실습과제5
- `char words[5][50];`
  - 최대 49개의 문자와 널 문자를 저장할 수 있는 문자 배열 5개를 선언한다.

- `char min_word[50];`, `char max_word[50];`
  - 사전순으로 가장 앞에 오는 문자열과 가장 뒤에 오는 문자열을 저장할 배열을 선언한다.

- `for (int i = 0; i < 5; i++)`
  - 총 5개의 문자열을 입력받고 비교하기 위해 반복한다.

- `scanf("%49s", words[i]);`
  - 문자열을 입력받아 `words[i]`에 저장한다. `%49s`는 배열 크기를 고려하여 최대 49개의 문자만 입력받도록 제한한다. 공백이 입력되면 그 앞까지만 읽는다.

- `if (i == 0)`
  - 첫 번째 문자열을 입력받았는지 확인한다. 첫 문자열을 비교의 기준으로 사용한다.

- `strcpy(min_word, words[i]);`
  - 현재 문자열을 사전순으로 가장 앞에 오는 문자열로 저장한다.

- `strcpy(max_word, words[i]);`
  - 현재 문자열을 사전순으로 가장 뒤에 오는 문자열로 저장한다.

- `strcmp(words[i], min_word) < 0`
  - 현재 문자열이 기존의 최소 문자열보다 사전순으로 앞에 있는지 비교한다. 음수가 반환되면 현재 문자열이 더 앞에 있다.

- `strcmp(words[i], max_word) > 0`
  - 현재 문자열이 기존의 최대 문자열보다 사전순으로 뒤에 있는지 비교한다. 양수가 반환되면 현재 문자열이 더 뒤에 있다.

- `strcpy(min_word, words[i]);`, `strcpy(max_word, words[i]);`
  - 비교 결과에 따라 최소 또는 최대 문자열을 현재 문자열로 갱신한다.

- `printf("제일앞 : %s\n", min_word);`
  - 사전순으로 가장 앞에 오는 문자열을 출력한다.

- `printf("제일뒤 : %s\n", max_word);`
  - 사전순으로 가장 뒤에 오는 문자열을 출력한다.
