# 실습과제 1
## 1. 배열명의 의미를 설명하라.

배열명은 배열의 첫 번째 원소가 저장된 주소를 의미한다.
따라서 배열명을 이용하면 배열의 첫 번째 원소부터 차례대로 접근할 수 있다.

## 2. 배열 표현과 포인터(주소) 표현의 변환 공식을 설명하라.

배열 표현인 `a[i]`는 주소를 이용한 표현인 `*(a + i)`로 바꿀 수 있다.

```c
a[i] == *(a + i)
```

포인터 변수 `p`를 사용할 때도 마찬가지이다.

```c
p[i] == *(p + i)
```

즉, 배열 표현과 포인터 표현은 형태는 다르지만 같은 원소를 나타낸다.

## 3. 배열의 첫 번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있는 이유를 설명하라.

배열의 원소들은 메모리에 연속적으로 저장된다.
따라서 첫 번째 원소의 주소를 알고 있으면 인덱스만큼 이동하여 다른 원소의 주소도 구할 수 있다.

```c
a + i
```

이때 포인터의 자료형에 따라 이동할 크기가 자동으로 계산된다.

## 4. 배열의 첫 번째 요소의 주소만 알면 모든 원소의 값을 계산할 수 있는 이유를 설명하라.

배열의 원소들이 메모리에 연속적으로 저장되기 때문이다.
첫 번째 원소의 주소에서 원하는 원소의 위치까지 이동한 다음 `*` 연산자를 사용하면 해당 위치에 저장된 값을 가져올 수 있다.

```c
*(a + i)
```

## 5. 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.

포인터에는 다음과 같은 연산을 사용할 수 있다.

- `p++` : 포인터를 다음 원소의 주소로 이동시킨다.
- `p--` : 포인터를 이전 원소의 주소로 이동시킨다.
- `p + n` : 현재 위치에서 n개의 원소만큼 앞으로 이동한 주소를 구한다.
- `p - n` : 현재 위치에서 n개의 원소만큼 뒤로 이동한 주소를 구한다.
- `p1 - p2` : 두 포인터 사이의 원소 개수를 구한다.
- `*p` : 포인터가 가리키는 위치의 값을 가져온다.

## 6. 포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까?

포인터에는 일반적인 숫자가 아니라 메모리 주소가 저장된다.
자료형마다 메모리에서 차지하는 크기가 다르기 때문에 포인터를 단순히 1씩 증가시키면 다음 원소로 정확하게 이동할 수 없다.

따라서 포인터에 1을 더하면 주소값이 단순히 1 증가하는 것이 아니라, 포인터가 가리키는 자료형의 크기만큼 이동하도록 정의되어 있다.

예를 들어 `int`형 포인터에 1을 더하면 다음 `int`형 원소의 주소로 이동한다.
# 실습과제2
```c
int *ptr = grade;
```

- 배열 `grade`의 첫 번째 요소의 주소를 포인터 `ptr`에 저장한다.

```c
scanf("%d", ptr + i);
```
- 기존의 `&grade[i]`를 `ptr + i`로 변경하였다.
- `ptr + i`는 배열의 i번째 요소의 주소를 의미한다.
# 실습과제3
```c
a++
```

-  현재 값을 사용한 후 1 증가시킨다.

```c
++a
```

-  값을 먼저 1 증가시킨 후 사용한다.

## 잘못된 이유

```c
sum += *a++;
```

- 배열 이름 `a`는 배열의 시작 주소를 나타내지만 값을 변경할 수 없는 주소이므로 `a++` 연산을 수행할 수 없다.
- 따라서 컴파일 오류가 발생한다.
- 배열의 다음 요소로 이동하려면 배열을 가리키는 별도의 포인터를 사용해야 한다.


- 기존의 `grade[i]`를 `*(ptr + i)`로 변경하였다.
- `*` 연산자를 사용하여 `ptr + i`가 가리키는 배열 요소의 값을 가져온다.
- # 변경된 코드 설명

```c
int *p = a;
```

- 배열 `a`의 첫 번째 요소의 주소를 포인터 `p`에 저장한다.

```c
sum += *p++;
```

- `*p++`은 현재 `p`가 가리키는 값을 먼저 사용한 후 `p`를 다음 배열 요소로 이동시킨다.
- 따라서 `10`, `20`, `30`을 차례대로 `sum`에 더할 수 있다.

# 실습과제4-1
```c
double arr[5];
```
- 실수형 배열 `arr`을 선언하여 5개의 실수를 저장한다.

```c
double *ptr = arr;
```
- 포인터 변수 `ptr`을 선언하고 배열의 첫 번째 요소를 가리키도록 한다.

```c
scanf("%lf", &arr[i]);
```
- 키보드로 입력받은 실수를 배열 `arr`에 저장한다.

```c
arr[i] += 2;
```
- 배열의 각 요소에 2를 더하여 값을 2씩 증가시킨다.

```c
printf("%.2f ", arr[i]);
```
- 2씩 증가된 배열의 실수 값을 소수점 둘째 자리까지 출력한다.
# 실습과제4-2
```c
double arr[5];
```
- 실수형 배열 `arr`을 선언하여 5개의 실수를 저장한다.

```c
double *ptr = arr;
```
- 포인터 변수 `ptr`을 선언하고 배열의 첫 번째 요소를 가리키도록 한다.

```c
scanf("%lf", ptr++);
```
- `ptr`이 가리키는 배열 요소에 키보드로 입력받은 실수를 저장한다.
- `ptr++`을 사용하여 입력 후 포인터가 다음 배열 요소를 가리키도록 한다.
- 따라서 반복할 때마다 다음 배열 요소에 실수가 저장된다.

```c
ptr = arr;
```
- 포인터 `ptr`을 다시 배열의 첫 번째 요소를 가리키도록 한다.

```c
*ptr++ += 2;
```
- `ptr`이 가리키는 배열 요소의 값을 2 증가시킨다.
- `ptr++`을 사용하여 연산 후 포인터가 다음 배열 요소를 가리키도록 한다.

```c
printf("%.2f ", arr[i]);
```
- 2씩 증가된 배열의 실수 값을 소수점 둘째 자리까지 출력한다.

# 실습과제 5-3
```c
float a[5];
```
- 실수형 배열 `a`를 선언하여 5개의 실수를 저장한다.

```c
float sum = 0.0f;
```
- 배열에 저장된 값의 합계를 저장할 실수형 변수 `sum`을 선언하고 0으로 초기화한다.

```c
float *p = a;
```
- 포인터 변수 `p`를 선언하고 배열 `a`의 첫 번째 요소를 가리키도록 한다.

```c
scanf("%f", p + i);
```
- `p + i`를 이용하여 배열의 각 요소의 주소를 구하고 키보드로 입력받은 실수를 저장한다.
- 포인터 변수의 덧셈 연산을 이용하여 배열의 각 요소에 접근한다.

### 1. 배열 표현

```c
sum += a[i];
```
- 배열 표현인 `a[i]`를 이용하여 각 배열 요소를 `sum`에 더한다.

### 2. 배열명을 이용한 주소 표현

```c
sum += *(a + i);
```
- 배열 이름 `a`에 `i`를 더하여 해당 배열 요소의 주소를 구한다.
- `*` 연산자를 이용하여 해당 주소의 값을 가져와 `sum`에 더한다.

### 3. 포인터 변수를 이용한 배열 표현

```c
sum += p[i];
```
- 포인터 변수 `p`를 배열처럼 사용하여 각 요소의 값을 `sum`에 더한다.

### 4. 포인터 변수를 이용한 주소 표현

```c
sum += *(p + i);
```
- 포인터 변수 `p`에 `i`를 더하여 각 배열 요소에 접근한다.
- `*` 연산자를 이용하여 해당 위치의 값을 가져와 `sum`에 더한다.

### 5. 포인터의 증감 연산자를 이용한 주소 표현

```c
p = a;
```
- 포인터 `p`를 다시 배열의 첫 번째 요소를 가리키도록 초기화한다.

```c
sum += *p++;
```
- `p`가 가리키는 배열 요소의 값을 `sum`에 더한다.
- `p++`을 이용하여 다음 배열 요소를 가리키도록 포인터를 증가시킨다.
- 포인터의 증감 연산자를 이용하여 배열의 모든 요소의 합을 구한다.
