# 실습과제 1

- 문자는 메모리에 아스키 코드(ASCII)에 해당하는 정수값으로 저장된다. 문자 'A'는 아스키 코드 값인 65로 저장된다.

- 널문자 '\0'는 문자열의 끝을 나타내는 문자이다. 문자열이 어디에서 끝나는지 구분하기 위해 문자열의 마지막에 저장된다.

- 문자열의 첫 번째 문자부터 하나씩 확인하면서 널문자 '\0'가 나올 때까지 탐색한다. 널문자 '\0'가 발견되면 그 위치가 문자열의 끝이다.

- 문자열의 첫 번째 문자부터 하나씩 검사하면서 널문자 '\0'가 나올 때까지 문자의 개수를 센다. 널문자를 만나면 반복을 종료하고, 지금까지 센 문자의 개수가 문자열의 길이가 된다.
# 실습과제2
```c
char str[100];
```

* 최대 99개의 문자를 저장할 수 있는 문자 배열 `str`을 선언한다.
* 문자열의 마지막에는 `'\0'`이 저장되므로 배열 크기보다 1개 적은 문자를 저장할 수 있다.

```c
int i = 0;
```

* 문자열의 문자를 순서대로 확인하기 위한 인덱스 변수 `i`를 선언하고 0으로 초기화한다.

```c
printf("문자열을 입력하시오:");
```

* 사용자에게 문자열을 입력하도록 안내하는 문장을 출력한다.

```c
scanf("%s", str);
```

* 사용자에게 문자열을 입력받아 `str` 배열에 저장한다.
* 배열 이름 `str`은 배열의 첫 번째 원소의 주소를 의미하므로 `&str`이 아닌 `str`을 사용한다.

```c
while (str[i] != '\0')
```

* `str[i]`가 문자열의 끝을 나타내는 `'\0'`이 아닐 때까지 반복한다.
* 문자열의 각 문자를 처음부터 끝까지 확인한다.

```c
printf("%d번째문자 %c\n", i + 1, str[i]);
```

* 현재 문자의 순서와 문자를 출력한다.
* `i + 1`은 사람이 보기 편하도록 첫 번째 문자를 1번째로 표시하기 위해 사용한다.
* `%c`는 문자 하나를 출력하는 서식 지정자이다.

```c
i++;
```

# 실습과제3
```c
char str[100];
int i = 0;
```
- 문자열을 저장할 문자형 배열 `str`을 선언한다.
- 변수 `i`는 문자열의 각 문자를 차례대로 확인하기 위해 사용한다.

```c
printf("문자열을 입력하시오:");
fgets(str, sizeof(str), stdin);
```
- 키보드로 입력받은 문자열을 배열 `str`에 저장한다.
- 공백을 포함하여 최대 99개의 문자를 입력받고, 마지막에 널 문자 `'\0'`을 저장한다.

```c
while (str[i] != '\0')
```
- 현재 문자가 널 문자 `'\0'`이 아닐 동안 반복한다.
- 널 문자를 만나면 문자열이 끝난 것으로 판단하여 반복을 종료한다.

```c
if (str[i] >= 'A' && str[i] <= 'Z')
    str[i] = str[i] + ('a' - 'A');
```
- 현재 문자가 대문자인지 확인한다.
- 대문자이면 소문자와 대문자의 문자 코드 차이만큼 더하여 소문자로 변환한다.

```c
else if (str[i] >= 'a' && str[i] <= 'z')
    str[i] = str[i] - ('a' - 'A');
```
- 현재 문자가 소문자인지 확인한다.
- 소문자이면 소문자와 대문자의 문자 코드 차이만큼 빼서 대문자로 변환한다.
- 영문자가 아닌 숫자, 공백, 기호 등은 그대로 유지한다.

```c
i++;
```
- 다음 문자를 확인하기 위해 배열의 인덱스를 1 증가시킨다.

```c
printf("변환결과 : %s", str);
```
- 대문자와 소문자가 변환된 문자열을 출력한다.

# 실습과제4

```c
char str1[100], str2[100];
int i = 0;
```
- 두 문자열을 저장할 문자형 배열 `str1`, `str2`를 선언한다.
- 변수 `i`는 첫 번째 문자부터 차례대로 비교하기 위해 사용한다.

```c
printf("문자열을 입력하시오:");
scanf("%99s", str1);

printf("문자열을 입력하시오:");
scanf("%99s", str2);
```
- 키보드로 입력받은 두 문자열을 각각 `str1`, `str2`에 저장한다.
- `%99s`를 사용하여 각 배열에 최대 99개의 문자와 문자열의 끝을 나타내는 널 문자를 저장한다.
- 입력하는 문자열은 모두 소문자이며, 공백이 없는 단어를 입력한다.

```c
while (str1[i] != '\0' && str1[i] == str2[i])
    i++;
```
- 첫 번째 문자열이 끝나지 않았고 같은 위치의 두 문자가 같으면 다음 문자로 이동한다.
- 서로 다른 문자가 나오거나 문자열이 끝날 때까지 반복한다.

```c
if (str1[i] <= str2[i])
    printf("사전에서 앞에 나오는 문자열: %s\n", str1);
```
- 두 문자의 아스키코드를 비교하여 첫 번째 문자열의 문자가 더 작으면 `str1`을 출력한다.
- 두 문자열이 완전히 같아도 `str1`을 출력한다.
- 첫 번째 문자열이 두 번째 문자열의 앞부분과 같고 먼저 끝나면 널 문자의 값이 소문자의 아스키코드보다 작으므로 `str1`을 출력한다.

```c
else
    printf("사전에서 앞에 나오는 문자열: %s\n", str2);
```
- 두 번째 문자열의 문자가 더 작으면 사전에서 앞에 나오는 문자열인 `str2`를 출력한다.

# 실습과제5
```c
char* fruits[] = {"apple", "blueberry", "orange", "melon"};
```
- 문자열의 시작 주소를 저장하는 포인터 배열 `fruits`를 선언한다.
- 배열의 각 요소는 `"apple"`, `"blueberry"`, `"orange"`, `"melon"`을 각각 가리킨다.

```c
int i, min = 0;
```
- 변수 `i`는 배열의 요소를 차례대로 확인하기 위해 사용한다.
- 변수 `min`은 첫 번째 문자가 가장 작은 문자열의 인덱스를 저장한다.
- 처음에는 첫 번째 문자열을 기준으로 비교하기 위해 `min`을 0으로 초기화한다.

```c
for (i = 1; i < 4; i++)
```
- 두 번째 문자열부터 마지막 문자열까지 차례대로 확인한다.
- 첫 번째 문자열은 이미 비교 기준으로 정했으므로 인덱스 1부터 시작한다.

```c
if (fruits[i][0] < fruits[min][0])
    min = i;
```
- `fruits[i][0]`은 현재 확인하는 문자열의 첫 번째 문자를 나타낸다.
- 현재 문자열의 첫 번째 문자가 기준 문자열의 첫 번째 문자보다 작으면 `min`을 현재 인덱스로 변경한다.
- 반복이 끝나면 `min`에는 첫 번째 문자가 가장 작은 문자열의 인덱스가 저장된다.

```c
printf("사전에서 가장 앞에 나오는 문자열: %s\n", fruits[min]);
```
- `fruits[min]`이 가리키는 문자열을 출력한다.
- 주어진 문자열 중 첫 번째 문자가 가장 작은 문자열은 `"apple"`이므로 `apple`이 출력된다.
