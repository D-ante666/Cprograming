# 실습과제1
- 스트림은 입력장치, 운영프로그램, 출력장치 사이를 입력스트림 출력스트림이 경로가 되어서 이어주는역할,
  버퍼는 스트림내부에 포함되어있고, 입출력장치와 프로그램 사이에 존재해데이터를 저장하는 메모리공간

-  장점은 처리시간을 단축, 데이터 손실 방지, 버퍼를 사용하면 엔터키가 입력되기 전에 데이터의 수정이 가능함
   단점은 버퍼에 남아있는 문자가 있으면 버퍼를 읽어올 때 남아있던게 읽어와진다
   
-  버퍼에 남아있는 데이터를 scanf가 읽어온다

-  버퍼가 가득차거나 문장입력이 완료될때 출력장치로 전송하고 버퍼를 비운다

- printf함수실행되면 printf함수에서 데이터를 버퍼가 운영체제에 전송하고, 운영체제의 함수가 버퍼의 데이터를 모니터로 전송하고 버퍼에서 삭제함

- scanf함수가 실행되면 버퍼가 비어있으면 운영체제함수를 호출하고 대기, 운영체제함수는 입력된 데이터를 버퍼로 전송하고 scnaf함수를 호출함,
  이후 scnaf함수가 입력데이터를 변수에 저장하고 버퍼에서 삭제함
